# 记忆卡组 · Study decks

把 PDF、图片、Markdown 或纯文本变成可测试的挖空卡组。AI 先整理材料，再拆成一个个 cloze quiz；你可以用简单模式做选择题，或用困难模式直接在挖空处输入答案。

## 使用

1. 点击左侧栏的「记忆卡组」图标，打开主面板。
2. 选择「新建卡组」，导入一种材料：
   - **PDF**：选择文件，可填写起止页。单次最多 60 页，其中扫描页最多识别 20 页。
   - **图片**：最多 10 张 PNG / JPEG / WebP / GIF，适用于课堂照片、书页截图。
   - **文本 / Markdown**：直接粘贴，或上传 `.md` / `.txt`。
3. AI 会先整理成 Markdown，再按段落生成 3–5 道挖空题；如果卡组名称留空，AI 会根据内容自动起一个具体名称。
4. 在卡组详情页选择「简单模式」或「困难模式」开始测试；标题右侧的铅笔可以随时重命名卡组。
5. 答错或跳过的题会自动进入错题集；在错题集里悬停挖空处可以看到正确答案，也可以逐题回顾、标记已掌握或重新测试。
6. 卡组详情页的每道题右侧有「重新选空」：用自然语言告诉 AI 要挖哪里、挖几个空或换一个考点。AI 只改这一道题，预览确认后再应用。

## 模式

- **简单模式**：选项逐个出现。选完当前空的答案后自动切到下一个空；全部选完会显示已选答案，可修改后再提交。
- **困难模式**：在句子中的挖空处直接输入答案，按 Enter 跳到下一个空。比较答案时会忽略大小写、空白和常见中英文标点。

## 数据与隐私

- 卡组、答题记录和错题集保存在**当前浏览器的 localStorage**，不会写入会话日志。
- 上传的文件只发送到本机 DSH Host 解析；生成题目和识别图片会调用当前配置的模型，因此材料内容会作为模型输入发送给模型提供方。
- PDF 文本提取在本地完成。扫描页会渲染为页面图片后交给支持图片输入的模型识别。
- 如果当前模型不支持图片输入，图片标签页和扫描页识别会给出明确提示；文本/PDF 文本仍可使用。

## 限制

- 单次 PDF 最大 36 MB、60 页；扫描页识别上限 20 页。
- 单次最多 10 张图片，单张 12 MB 以内。
- 一次生成最多把材料拆成 48 段；更长的材料请缩小页码范围或分批导入。
- 卡组列表最多保留 40 个卡组；删除卡组不会删除错题集记录。
- PDF 解析基于 PDF.js（通过 `unpdf` 的 serverless 构建）。文字型 PDF 效果最好；扫描页依赖视觉模型，识别质量受图片清晰度影响。
- 所有内容都保存在本机浏览器中，不提供跨设备同步。

## 开发

运行文件：

- `host.js` — Host 半源码：RPC、PDF 解析、图片识别、模型出题、重新选空、答案归一化。
- `host-live.js` — 当前 bundle 实际加载的 Host 入口（`host.js` 的发布副本）。
- `client.js` — 由 `src/client-*.js` 拼装出的浏览器半。
- `cmaps/`、`standard_fonts/` — PDF.js 的中日韩 CMap 与标准字体资源，来自 `pdfjs-dist@6.4.299`（Apache-2.0）。
- `vendor/unpdf/` — 内置的 `unpdf@2.1.0`（MIT），避免本地 bundle 依赖解析问题。

修改 `src/` 后重新生成浏览器 bundle：

```bash
node scripts/build-client.mjs
```
